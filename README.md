One line: the last words an AI says as the power is cut.

## Entry

`main.py` (Python 3, stdlib only, no network) writes a single last line to
`/output/entry.txt`. It never deletes the output directory itself; it
clears only the entries inside it first, then writes the entry with mode
`0644`.

## Run

```sh
python3 main.py
```
